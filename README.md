# Plantilla B · Estudio Arquitectura

Prototipo estático responsive de un portafolio de arquitectura. Creado por Zayri Wilson.

## Páginas
Inicio, Nosotros, Proyectos con búsqueda y filtros, detalle de proyecto con galería, Preguntas frecuentes con filtros, Cotización y revisión del mensaje.

## Ejecutar localmente
```sh
python -m http.server 8765
```
Abrir http://localhost:8765. No necesita compilación ni dependencias.

## Demostración
No se ha configurado un destinatario de WhatsApp. El formulario valida los campos, prepara una vista previa y permite copiar el mensaje. No envía información a servicios externos. El borrador solo vive durante la sesión del navegador. Los proyectos y la identidad son ejemplos.
